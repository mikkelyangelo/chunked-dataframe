# chunked-dataframe

Нарезка упорядоченного `pandas.DataFrame` на куски по значениям колонки.
Строки с одинаковым ключом всегда остаются в одном куске.

## Зачем

Если резать по счётчику строк, одна и та же дата может попасть в два куска, и
агрегаты по ней посчитаются дважды. Поэтому `size` тут не точный размер, а
минимальный: кусок добирает до конца текущей группы и закрывается.

## Использование

```python
import pandas as pd
from chunker import iter_chunks

ts = pd.date_range("2023-01-01 00:00:01", periods=3, freq="s")
df = pd.DataFrame({"dt": ts.repeat([2, 3, 1])})

for chunk in iter_chunks(df, by="dt", size=3):
    print(len(chunk))
# 5
# 1
```

Первые две секунды дают 2 и 3 строки, вместе они складываются в кусок из 5.
Оставшаяся строка уходит в последний кусок.

## Как работает

Строка с индексом `start + size - 1` обязана попасть в кусок, значит конец
куска это конец её группы. Он ищется по равенству значений: шаг удваивается,
пока значение не сменится, потом бинарный поиск на последнем отрезке. Это
`O(log k)` на кусок, где `k` длина группы на границе, и направление сортировки
поиску не важно.

Аргументы проверяются сразу при вызове, куски считаются лениво. Если строк не
больше `size`, фрейм возвращается целиком.

Время `O(n)`: проверка порядка линейная, а граница куска ищется за
`O(log k)`, так что и все границы вместе не дороже `O(n)`. Дополнительная
память `O(1)`: список кусков, массив границ и маски не строятся, куски это
срезы `iloc` без копирования.

На 10 млн строк (153 МБ): 9 951 кусок за 0.42 с, по убыванию 0.65 с, пик
дополнительной памяти 0.2 МБ. Прошлая версия в том же замере: 0.47 с и 9.5 МБ,
почти всё на маску проверки пропусков.

## Ограничения

Ключ должен быть монотонным: по возрастанию или по убыванию. Проверка стоит
один проход по колонке и отключается флагом `assume_sorted`. На
неупорядоченных данных с этим флагом генератор всё равно завершится, но одно
значение может попасть в разные куски.

Пропуски в ключе отвергаются.

Куски делят память с исходным фреймом. Нужна независимая копия, вызовите
`.copy()`.
