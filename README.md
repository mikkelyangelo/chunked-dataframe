# chunked-dataframe

Нарезка отсортированного `pandas.DataFrame` на куски по значениям колонки.
Строки с одинаковым ключом всегда остаются в одном куске.

## Зачем

Если резать по счётчику строк, одна и та же дата может попасть в два куска, и
агрегаты по ней посчитаются дважды. Поэтому `size` тут не точный размер, а
минимальный: кусок добирает до конца текущей группы и закрывается.

## Использование

```python
import pandas as pd
from chunker import iter_chunks

ts = pd.date_range("2023-01-01 00:00:01", periods=3, freq="s")
df = pd.DataFrame({"dt": ts.repeat([2, 3, 1])})

for chunk in iter_chunks(df, by="dt", size=3):
    print(len(chunk))
# 5
# 1
```

Первые две секунды дают 2 и 3 строки, вместе они складываются в кусок из 5.
Оставшаяся строка уходит в последний кусок.

## Как работает

Строка с индексом `start + size - 1` обязана попасть в кусок, значит конец
куска это конец её группы. Находим его бинарным поиском:
`searchsorted(pivot, side="right")`.

Время `O(g * log n)`, где `g` это число кусков. Дополнительная память `O(1)`,
список кусков и массив границ не строятся. Куски возвращаются срезами `iloc`
без копирования.

На 10 млн строк (153 МБ): 10 000 кусков за 6.7 с, пик дополнительной памяти
9.5 МБ.

## Ограничения

Ключ должен быть отсортирован по возрастанию. Проверка стоит один проход по
колонке, отключается флагом `assume_sorted`.

Пропуски в ключе отвергаются: `NaT` ломает монотонность, на которой держится
бинарный поиск.

Куски делят память с исходным фреймом. Нужна независимая копия, вызовите
`.copy()`.
